# OpenCV-Artistic-Filters

## Artistic Image Filtering and Pencil Sketch Using OpenCV

This project demonstrates artistic image processing techniques using Python and OpenCV. The program applies multiple image filtering operations such as smoothing, sharpening, edge enhancement, and pencil sketch transformation to generate visually appealing artistic effects.

---

# Features

- Read and display input images
- Apply Averaging Filter
- Apply Gaussian Blur Filter
- Apply Median Filter
- Apply Sharpening Filters
- Perform Edge Detection
- Generate Pencil Sketch Effect
- Compare original and processed outputs

---

# Technologies Used

- Python 3.x
- OpenCV (`cv2`)
- NumPy
- Matplotlib
- Jupyter Notebook / VS Code
---

# Filters Implemented

## Smoothing Filters

### Averaging Filter
Reduces image noise by averaging neighboring pixel values.

### Gaussian Filter
Applies Gaussian blur to smooth the image while preserving edges.

### Median Filter
Efficiently removes salt-and-pepper noise from images.

---

# Sharpening Filter

### Sharpening Filter
Enhances image clarity and highlights important details.

---

# Artistic Effects

### Pencil Sketch Filter
Transforms a normal image into a realistic black-and-white pencil sketch using OpenCV.

---

# Algorithm

1. Import required libraries
2. Read the input image
3. Convert image from BGR to RGB format
4. Apply smoothing filters
5. Apply sharpening filters
6. Perform edge detection
7. Generate pencil sketch effect
8. Display outputs using Matplotlib
